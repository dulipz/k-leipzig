**Select** — dropdown for choosing a date, party size, voucher value, etc.

```jsx
<Select label="Vorstellung" options={[
  { value: "1", label: "Fr · 13.03. · 19:30" },
  { value: "2", label: "Sa · 14.03. · 19:30" },
]} />
```

Styled to match Input with a gold caret. Provide `options` as data or `<option>` children.

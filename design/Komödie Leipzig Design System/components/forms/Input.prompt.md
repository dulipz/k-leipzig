**Input** — text field for reservation/contact/search forms.

```jsx
<Input label="E-Mail" type="email" placeholder="ihre@email.de" helper="Für die Bestätigung." />
<Input label="Gäste" error="Bitte Anzahl angeben." />
```

Pass `tone="stage"` on dark surfaces, `iconLeft`/`iconRight` for adornments, `error` to show the red invalid state.
